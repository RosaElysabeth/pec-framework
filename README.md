# PEC Framework — Predict · Explain · Certify

Framework de certification intégré pour l'Intelligence Artificielle Explicable (XAI).

## 4 Plateformes

| Port | App | Description |
|------|-----|-------------|
| 8501 | PEC Mada | Audit complet — 6 modèles × 3 cibles nutritionnelles (Madagascar) |
| 8502 | PEC Aide | Aide à la décision — Upload CSV, certification automatique |
| 8503 | PEC What | Prédiction interactive — What-If par région/scénario |
| 8504 | PEC Gen | Généralisation multi-domaines — Climat, Fintech, Santé |

## Installation locale

```bash
pip install -r requirements.txt
```
